Kelola Konten

Berita & akademik sekolah

Tambahkan, ubah, atau hapus konten yang tampil di tab Berita Sekolah dan menu Akademik. Perubahan langsung tersimpan di browser ini.

Tambah berita

Berita terbaru akan tampil paling depan.

Berita tersimpan

Urutan tampil di website mengikuti urutan di bawah ini.

Tambah agenda

Agenda baru ditambahkan di urutan paling bawah.

Agenda tersimpan

Ditampilkan pada tab Akademik → Kalender Akademik.

Tambah prestasi

Prestasi baru ditambahkan di urutan paling bawah.

Prestasi tersimpan

Ditampilkan pada tab Akademik → Prestasi.

Ekspor data

Unduh cadangan berita, kalender, dan prestasi dalam satu file JSON.

Impor data

Pulihkan konten dari file cadangan. Data yang ada saat ini akan diganti.

Ganti kata sandi

Kata sandi tidak cocok atau kurang dari 6 karakter.

Reset konten

Kembalikan berita, kalender, dan prestasi ke data awal website.

Data admin disimpan di browser ini (localStorage). Agar tampil di komputer lain atau untuk semua pengunjung, gunakan tombol Ekspor data, lalu impor di browser tersebut. Halaman ini hanya pengunci tampilan, bukan sistem keamanan server.
